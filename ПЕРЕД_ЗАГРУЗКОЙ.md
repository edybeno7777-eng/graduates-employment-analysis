# Публикация проекта на GitHub

1. Открой существующий репозиторий `graduates-employment-analysis` в GitHub Desktop через File → Clone Repository.
2. Распакуй этот архив. Перенеси в папку репозитория **содержимое** архива, а не сам ZIP: `README.md`, `Solving_VTR_2021.ipynb`, `requirements.txt`, `.gitignore`, папку `data`.
3. Если в репозитории уже есть `Solving.ipynb`, старые PDF/DOCX или прежний README, оставь только актуальную версию ноутбука и README; оригиналы сохраняй у себя отдельно.
4. Проверь право открытой публикации исходных микроданных. Если распространять XLSX нельзя, **не публикуй его** — в README укажи ссылку на официальный источник и инструкцию получения данных.
5. В GitHub Desktop проверь Changes → Commit to main → Push origin.
6. Открой репозиторий в браузере: README виден на главной странице, ноутбук открывается и показывает графики, структура `data/ВТР_2021.xlsx` совпадает с путём в коде (если файл разрешено опубликовать).
7. В About добавь: `Анализ продолжительности поиска работы выпускников по данным Росстата (ВТР-2021). Python, pandas, статистика.`; Topics: `python`, `pandas`, `data-analysis`, `statistics`, `rosstat`.
