# Анализ трудоустройства выпускников — ВТР-2021

Анализ продолжительности поиска работы выпускниками на основе выборочного наблюдения Росстата за 2021 год.

## Данные

Источник: [Росстат — ВТР-2021](https://rosstat.gov.ru/free_doc/new_site/population/trud/itog_trudoustr_2021/index.html). В исходном файле 21 526 наблюдений и 209 признаков; для анализа отобраны 10 столбцов. Основная переменная — `DPS_RB5` (продолжительность поиска работы, месяцы).

## Анализ

- Распределения возраста и срока поиска работы: описательная статистика, гистограммы и box plot.
- Сравнение групп по возрасту, форме обучения, образованию и федеральному округу.
- Корреляционное отношение (η), доля межгрупповой вариации (η²) и непараметрические сравнения по возрастным группам и формам обучения.
- Сравнение показателей по месяцам опроса (без прогноза временного ряда).

## Результаты

- Средняя продолжительность поиска работы — **2,46 месяца**, медиана — **0,5 месяца**; сильная правосторонняя асимметрия (4,32).
- В выборке для сравнения форм обучения (20 711 наблюдений) средний срок: очная — **2,86 месяца**, заочная — **1,31**, очно-заочная — **1,50**.
- Для формы обучения η² ≈ **0,011**: на неё приходится около **1,1%** общей вариации срока поиска работы в сравниваемой подвыборке. Это небольшой размер эффекта, даже при статистически значимых различиях между группами.
- Для групп возраста η² ≈ **0,005**, для федеральных округов — **0,002**.

## Как запустить

1. Установить Python и зависимости: `pip install -r requirements.txt`.
2. Убедиться, что таблица находится по пути `data/ВТР_2021.xlsx` и в ней есть лист `Sheet1`.
3. Открыть `Solving_VTR_2021.ipynb` в Jupyter Notebook или VS Code и выполнить ячейки по порядку.

Рассчитанные результаты и графики уже сохранены внутри ноутбука, поэтому их можно просмотреть и без запуска.

## Ограничения

Показатели рассчитаны без весов обследования и описывают рассматриваемую выборку. Групповые различия не являются доказательством причинной связи. Категория формы обучения, не соответствующая трём сравниваемым формам, исключена из соответствующей группировки (815 записей); остальные анализы используют свои определённые подвыборки.
